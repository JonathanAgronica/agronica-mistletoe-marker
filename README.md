# Agronica Mistletoe Marker

A small offline-capable PWA for marking mistletoe on the LEFT or RIGHT of a row using GPS, with KML export/import.

Live: https://jonathanagronica.github.io/agronica-mistletoe-marker/

## Use
Open the live URL over HTTPS (GPS requires a secure context) and add it to your home screen. Press START, then LEFT / RIGHT to drop marks; use MENU to export/share or import KML.

## Files
`index.html`, `app.js`, `kml.js`, `style.css`, `manifest.json`, `sw.js` (service worker), `icons/`. All paths are relative so the app works under a subpath.

## Hosting
GitHub Pages, branch `main`, root (`/`).
